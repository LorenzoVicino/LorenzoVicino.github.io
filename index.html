Project №01 TypeScript · React · Fastify · Docker

A local-first command center for every repository.

repo-control turns a workspace folder into a live operational view: repository health, scoped Git and branch actions, terminal and Docker tools, plus visual automations that can be inspected before they run. Everything stays on the local machine and inside the selected repository boundary.

Workspace
Clean, modified, ahead and behind state across every repository
Operations
Scoped Git, branches, terminal, VS Code and Docker Compose
Automations
Visual workflows with dry runs, reusable nodes and run history
v0.2.0 · MIT · Local-first github.com/LorenzoVicino/repo-control →
