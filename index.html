Una visione di prodotto.

01 / Developer tool2026 · Open source

repo-control

Un centro di controllo locale per tutti i repository.

Trasforma una cartella di lavoro in una vista operativa: stato dei repository, azioni Git contestuali, terminale, Docker e automazioni visuali. Tutto rimane sulla macchina e dentro i confini del repository selezionato.

Problema
Gestire molti repository senza perdere contesto.
Approccio
Local-first, operazioni circoscritte e dry run.
Stack
TypeScript · React · Fastify · Docker
